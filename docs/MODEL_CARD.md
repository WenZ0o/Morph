# Model card

**Intended use:** inspect a small deterministic artificial-life system, test interventions and demonstrate reproducible simulation UX.

**Not intended for:** medical decisions, tissue engineering, developmental-biology prediction, biological parameter estimation, or claims of organismal cognition.

**Important scaffold:** every founder cell carries an engineered target-memory coordinate. New cells can inherit a missing target slot. This makes repair observable but strongly constrains what the experiment can establish.
