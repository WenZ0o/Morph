# Quick start

## Portable build
1. Download the repository or release ZIP.
2. Open `MORPH-1.html` in a modern desktop browser.
3. Press **Run**.
4. Use **Intervention lab** to cut cells or apply a fixed perturbation.
5. Use **Experiments** to run a matched protocol to cycle 900.

## Source mode
Requires Node.js 20+.

```bash
npm start
```
Open `http://127.0.0.1:4173`.

No `npm install` is needed for the runtime, tests, benchmark or build.
