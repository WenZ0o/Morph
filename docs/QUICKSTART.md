# Quick start

## Offline repository mode
1. Download or clone the complete repository.
2. Keep the folder structure intact.
3. Double-click `MORPH-1.html` in a modern desktop browser.
4. Press **Run**.
5. Use **Intervention lab** to cut cells or apply a fixed perturbation.
6. Use **Experiments** to run a matched protocol to cycle 900.

No package installation or network access is required for this mode. If you want a single-file standalone build, run `npm run build` first.

## Source mode
Requires Node.js 20+.

```bash
npm start
```
Open `http://127.0.0.1:4173`.

No `npm install` is needed for the runtime, tests, benchmark or build.
